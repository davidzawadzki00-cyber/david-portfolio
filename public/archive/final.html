Part 2 — New Interactive Project

CarryMode.

CarryMode is an interactive everyday carry guide that helps users choose what to bring based on where they are going. Users can pick a setup for the gym, school or running, then rank options within categories like shoes, bags, audio and tech.

Open CarryMode View class projects

Project overview

The final project combines web design, interaction, visual layout and user choice.

The site uses an Apple-inspired visual style with large typography, rounded product cards, subtle animation, a slideshow, custom cursor, embedded video and front-end voting. Each setup is organized into categories, and each category leads to a ranking page where users vote on the best option. Item detail pages provide community-style notes before linking to an outside review or shopping page.

Multiple pages: Home, Gym, School, Run, Ranking and Detail pages
Interactivity: clickable setup cards, ranking and item pages
Images: product-style graphics and project screenshot
Video: embedded EDC video on the CarryMode homepage
Animation: scroll reveals, slideshow and hover effects
Links: outside item links including RunRepeat for running shoes
